# DONATION – Sistema de Doações

O **DONATION** é uma aplicação web desenvolvida com o objetivo de facilitar a conexão entre doadores, beneficiários e organizações não governamentais (ONGs), tornando o processo de doação e solicitação de itens mais organizado e acessível.

<details>
<summary>📌 Status do projeto</summary>

**Em desenvolvimento.** Algumas funcionalidades e melhorias ainda estão sendo trabalhadas.
</details>

## 🚀 Funcionalidades

- Cadastro e login de usuários.
- Diferentes perfis de acesso: doador, beneficiário e ONG.
- Cadastro e gerenciamento de itens para doação.
- Upload de imagens dos itens.
- Catálogo de doações com filtros.
- Solicitação de itens disponíveis.
- Acompanhamento das solicitações.
- Painéis específicos para os usuários.
- Recuperação de senha por e-mail.

## 🛠️ Tecnologias utilizadas

- **PHP** – desenvolvimento do backend.
- **MySQL** – gerenciamento do banco de dados.
- **HTML5** – estrutura das páginas.
- **CSS3** – estilização e layout.
- **JavaScript** – interatividade.
- **Composer** – gerenciamento de dependências.
- **PHPMailer** – envio de e-mails.

## ⚙️ Como executar o projeto

### Pré-requisitos

Antes de iniciar, é necessário ter instalado:

- PHP.
- MySQL.
- Servidor local, como XAMPP.
- Composer.
- Git (opcional).

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/RenatoBrelaz/SISTEMA-DOA-O-atualizado.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd SISTEMA-DOA-O-atualizado
   ```

3. Instale as dependências do Composer:

   ```bash
   composer install
   ```

4. Configure o banco de dados MySQL conforme as configurações utilizadas pelo projeto.

5. Configure a conexão com o banco de dados e as informações necessárias para o envio de e-mails.

6. Execute o projeto em seu servidor PHP local e acesse pelo navegador.

> **Observação:** os nomes dos arquivos de configuração e do banco de dados devem ser conferidos na estrutura do projeto antes da execução.
